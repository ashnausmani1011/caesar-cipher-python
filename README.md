# Caesar Cipher in Python

A Python implementation of the Caesar Cipher for encrypting and decrypting text using a shift value.

## Features

- Encrypts text using a shift value
- Decrypts encrypted text
- Supports uppercase and lowercase letters
- Validates the shift value

## How It Works

The Caesar Cipher shifts each letter in the alphabet by a fixed number of positions.

For example, with a shift of 3:

- A → D
- B → E
- C → F

## Example

**Encrypted:** Pbhentr vf sbhaq va hayvxryl cynprf.

**Decrypted:** Courage is found in unlikely places.
